# Raw Data

The raw TfL Cycle Hire journey files are not included in this repository
because of their size.

Files used for the analysis:

- `405JourneyDataExtract01Oct2024-14Oct2024.csv`
- `406JourneyDataExtract15Oct2024-31Oct2024.csv`

Source:
Transport for London (TfL) Cycling Open Data

The files should be downloaded from the official TfL cycling data portal
and placed in this directory before running the notebooks.
